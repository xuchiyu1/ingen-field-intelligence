- **LLM vs keyword baseline is not a clear win on this data.** The LLM made 4 errors on 100 held-out reports and the keyword baseline 6. A two-report difference on 100 reports cannot be distinguished from noise.
- **The keyword baseline is optimistically biased.** Its rules were written by the same person who wrote the corpus generator's templates, so they match the template wording. Template-based synthetic reports are also more regular than real field notes. Its 94% should not be expected on real InGen reports.
- **Most LLM errors trace to the taxonomy, not the prompt.** Two errors are weather-rule pauses ("Heavy rain, paused patrol per weather rule"): the E1 rule (weather stops the task, robot working as designed) overlaps the NO_INCIDENT rule (safety rule working as intended). One is a speech-recognition complaint ("doesn't understand one resident's accent") that fits both U2 and S5. Recommended fix: state in the guide that weather-rule pauses are E1, and that conversation or speech-understanding complaints from users are U2 unless a wrong AI decision is described.
- **Severity is the weak dimension.** Held-out severity agreement is 47% exact and 83% within one level (tuning split: 51% / 85%). Disagreement is systematic: the labeller rated collisions with objects as Level 4, the model as Level 1–2. Two runs of the same model also agreed on severity for only 75% of tuning reports. The severity rule (especially "or a safety risk" at Level 4) needs clarifying before severity is used in Week 3 analysis.
- **How the LLM was run.** Claude Code in print mode (`claude -p`) on the Claude subscription, model claude-opus-4-7, prompt classify_v1, one report per call, all tools disabled and an empty working directory, so the model saw only the prompt and the report text. The held-out split was run once. Reported costs are equivalent API costs, billed to the subscription rather than charged.
- **Full-corpus classification used batches of 25 reports per call** to fit subscription limits. On the 150 tuning reports, batched and single-call category predictions agreed on 150 of 150 (both 99.3% accurate).
- **One likely gold-label error on the tuning split:** R01477 ("heart-rate reading 49 BPM, resident was fine") was labelled NO_INCIDENT; under the S5 rule it is an AI detection error.
